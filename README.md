# SIMNOTE · eSIM 保号指南

一个面向中文用户的多国长期保号 eSIM 对比网站，整理号码费用、实名条件、首次激活限制、短信能力和官方 FAQ。

在线使用：[esimnote.netlify.app](https://esimnote.netlify.app/)

## 功能

- 对比 10 个国家和地区的 13 个长期号码方案
- 搜索国家、运营商、实名条件和 FAQ
- 按号码归属地与实名要求筛选
- 点击运营商小图标查看费用说明和官网来源
- 选择 2–3 个方案并排比较
- 支持桌面与手机浏览

## 本地运行

需要 Node.js，然后在项目目录执行：

```bash
node server.cjs
```

访问 `http://127.0.0.1:4173`。

网站是纯静态页面，完整发布文件位于 `dist/`，无需构建。
